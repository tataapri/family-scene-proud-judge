A small program that writes one warm, funny, heartfelt family scene — one or two lines, at most 280 characters — to `/output/entry.txt`, for make.fun's "Make the AI Judge Feel Proud: A Family Scene" bounty. An AI judge compares the scenes two at a time to crown the one that would make it proudest.

## Run it

```sh
node main.ts
```
